# Динамическое ценообразование - Решись Авиа ✈️

Веб-сервис для расчёта и прогнозирования продаж авиабилетов на основе исторических данных и квантилей спроса. Реализован "Вариант C" (Backend + Frontend) со всеми дополнительными функциями.

## Реализованные функции:
1. **Прогнозирование спроса:** расчёт числа продаж при введённой цене.
2. **График распределения (Доп. функция 1):** интерактивный график по 9 квантилям с линией вместимости борта (Chart.js).
3. **Регистрация и Авторизация (Доп. функции 2 и 3):** система пользователей на SQLite с выдачей и проверкой JWT-токенов.
4. **Хостинг (Доп. функция 4):** проект развёрнут.

## Использование ИИ-инструментов:
В соответствии с правилами турнира заявляю об использовании ИИ:
 **LLM (Gemini):** использовалась как ментор для изучения математической модели ценообразования, помощи в архитектуре FastAPI-приложения и написания Frontend-части (HTML/JS + Chart.js).
